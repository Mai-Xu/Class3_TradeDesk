## 项目 1 · 订单簿回放与模拟下单原型

目录：[`01_orderbook_sim/`](01_orderbook_sim/)

### 做什么

按股票逐笔回放买卖十档，并在此基础上提供一个**本地模拟下单**原型：
连续竞价限价委托、按价格与时间排队、部分成交、撤单、资金与持仓冻结，
附浏览器操作页面，全部只在本机运行。

### 功能

- **逐笔回放**：处理新增挂单、撤单、成交三类事件，生成十档盘口、最新价、累计成交量额。
- **模拟下单**：限价委托先与市场簿即时撮合（吃对手价），剩余量进入用户挂单簿；
  后续历史成交流水若价格交叉，按价格-时间优先对用户挂单做被动成交。
- **冻结与 T+1**：买入冻结资金、卖出冻结持仓；当日买入计入今仓、当日不可卖，
  日终结算（`/api/settle`）后才转为可卖。
- **交易规则**：区分主板与科创板的申报数量与有效申报价格范围，
  校验价格最小变动单位与普通已上市股票的涨跌幅。
- **操作页面**：行情十档、模拟账户、委托记录、模拟成交记录；服务仅绑定 `127.0.0.1`。

### 主板 / 科创板规则

| 项目 | 主板 | 科创板 |
| --- | --- | --- |
| 单笔申报数量 | 100 股起，须为 100 股整数倍 | 200 股起，超出部分按 1 股递增 |
| 涨跌幅 | ±10% | ±20% |
| 连续竞价有效申报价格范围 | 价格笼子 ±2% | 价格笼子 ±2% |
| 最小变动单位 | 0.01 元 | 0.01 元 |

> 交易所业务细则存在版本差异，全部参数集中在 `obsim/rules.py` 的 `BoardRules` 中，
> 可按课程口径调整。卖出时若持仓不足最小申报量，允许一次性全部卖出。

### 验证结果

| 检查 | 结果 |
| --- | --- |
| 股票数量 | 50 |
| 完整重放的事件数（委托 + 成交，剔除盘后频道） | 10,066,831 |
| 撤单找不到原单 | 0 |

| 同上，在标注时间所在秒内匹配 | 2320 / 2389 |
| 同上，加入相邻时间诊断后匹配 | 2323 / 2389 |

自测：核心测试 **11 / 11 通过**；页面接口检查 **15 / 15 通过**。

### 关键设计：委托与成交的联合处理

回放时同时消费逐笔委托与逐笔成交：

- 新增委托建单入簿，撤单按被撤数量减量；
- 成交按方向扣减**被动方（挂单方）**，集合竞价成交扣减双方。

**为什么只扣被动方**：上交所新增委托记录可能表示"立即成交后的剩余挂单量"，
因此不能把已成交量从后出现的剩余挂单里重复扣减一次。
采用该模型后，全量回放中"无效扣减（超出挂单剩余量）"为 **0**。

### 页面内容

- 逐股时间轴：最新价 / 开高低 / 累计成交量额 / 成交笔数曲线；
- 买卖十档阶梯（由回放生成的订单簿）；

### 回放得到的十档快照精度

对 50 只标的、3 秒快照的 20 个档位（买十档 + 卖十档）逐一比对。
逐笔消息与 3 秒快照之间存在一个**随消息速率变化的微小时间偏移**（行情网关队列延迟），
用上午行情校准该偏移、在下午做样本外评价：

| 指标 | 未校正 | 校准后（上午，样本内） | 校准后（下午，样本外） |
| --- | ---: | ---: | ---: |
| 最优买卖价完全一致 | 84.7% | 94.9% | **93.2%** |
| 十档价格一致 | 87.9% | — | **94.1%** |
| 十档价 + 量完全一致 | 81.4% | 94.4% | **92.6%** |

### 集合竞价复现

50 只标的的开盘与收盘集合竞价**全部逐笔一致**（笔数、价格、买卖双方订单号），
合计 38,867 笔，precision = recall = 100%。开盘集合竞价只用逐笔委托即可还原；
收盘集合竞价需要先用"委托 + 成交回报"把 14:57 的订单簿重建出来再撮合。

### 核心发现

1. **日内是"双 U 形 + 午间断点"**：价差、波动、成交量、撤单在开盘同时冲高，随后单调衰减；
   午间最清淡，尾盘再抬升；**深度与波动严格反向**。
2. **流动性横截面被最小变动价位主导**：相对价差与股价相关系数 **−0.83**；
   低价股被 0.01 元"顶"到 25 bp，高价股窄至 1 bp，但跳动点数很多。
3. **OFI 同期强、预测弱**：同期 OFI 解释 3 秒中价收益方差的 **14.2%**，
   但对未来收益的预测力仅 0.4%–0.5% 且随视野衰减。
4. **越靠近盘口预测越强**：买一失衡变化的 3 秒预测 R² 为 3.1%，是十档失衡（1.4%）的两倍；
   十档失衡的预测力随视野上升并在长视野反超。
5. **大单冲击以永久成分为主**：主动大单成交瞬间中价平均跳 +4.4 bp，300 秒后仍余 +4.0 bp；
   但用中位数看则是"冲高后回吐"，重尾使均值与中位呈现不同的冲击-恢复画像。
6. **盘口持续偏向买盘**：买一侧挂单比卖一侧厚约 +11%（买一）/ +22%（五档内）。
7. **撤单是"远单快撤"战术**：贴中间价的订单撤单率 26.8%，
   离中间价 20 跳以上的撤单率 64.7%、中位存活仅 11 秒。
8. **跨股票高度同步但板块块状**：50 只里 39 只相对市场因子最优领先滞后为 0 分钟；
   板块内相关显著（保险 0.72、券商 0.65、石油石化 0.63、通信 0.59、白酒 0.55、银行 0.47）。
9. **集合竞价占比小但尾盘强于早盘**：开盘竞价占全日成交额 0.59%，收盘竞价 1.06%。
10. **快照与逐笔总量高度自洽**：全日累计成交量（快照口径）/ 逐笔成交求和 = **99.94%**，
    区间级偏差主要来自约 0.15–1.0 秒的行情网关对齐偏移。
11. **价差约六成是逆向选择**：有效价差 6.77 bp = 实现价差 2.80 bp + 价格冲击 3.97 bp
    （冲击占 59%）；Kyle λ 中位约 28 bp/百万股；拆单迹象明显（相邻委托同向概率 66%）。

## 共同的数据口径（重要）

三个项目在动手前都先做了字段语义校验，结论一致：

| 字段 | 含义 |
| --- | --- |
| `ord.FunctionCode` | `66`='B' 买单、`83`='S' 卖单；`73/79/74/67/86` 为集合竞价/收盘/盘后阶段标记（每标的各 1 条） |
| `ord.OrderKind` | `65`='A' 新增委托、`68`='D' 撤单（`Volume` 为**被撤数量**）、`83`='S' 状态 |
| `ord.OrderOriNo` | 交易所订单号，**按频道分配**（同一号码会在不同股票出现，务必带 `Symbol`+`Channel`） |
| `exe.BidOrder` / `AskOrder` | 引用 `ord.OrderOriNo`；撤单记录同样引用被撤订单的 `OrderOriNo` |
| `exe.BSFlag` | `66`/`83` = 主动买 / 主动卖，`0` = 集合竞价成交 |
| `Time` | `int`，`HHMMSSmmm`（如 `92500000` = 09:25:00.000） |
| `Channel` | `1001`–`1008` 为股票竞价频道；`2301` 为**盘后固定价格交易**（15:05–15:30，价格取当日收盘价） |

### 一条关键结论：上交所逐笔委托只披露"进入订单簿"的委托

实测：一笔成交里**挂单方**的订单号在 `ord` 中命中率约 **99.9%**，
而**主动成交方**只有约 **8%**——下单即全部成交的委托不会出现在逐笔委托里。

直接影响：

- 只用逐笔委托**无法**还原连续竞价的逐笔成交；
- 但订单簿（从而十档行情快照）可以用"逐笔委托 + 成交回报"重建；
- 项目 3 中所有"委托行为"统计只覆盖挂单部分，解读时需注意这一截断。

### 另一条：快照与逐笔存在亚秒级时间偏移

逐笔消息与 3 秒快照之间存在约 **0.15–1.0 秒**的对齐偏移，且随消息速率增大，
指向行情网关队列延迟。**时间对齐只用于离线核验，不用于让策略提前获得未来盘口。**

## 脱敏与合规

仓库在整理上传前做了全量敏感信息扫描（正则覆盖：私钥块、GitHub / OpenAI / AWS 令牌、
通用 `key/secret/token/password` 赋值、手机号、邮箱、身份证号、含凭证 URL、Cookie 字段、
学号样式），结果：

- **未发现**任何私钥、访问令牌、账号密码、AuthCode 或凭据；
- **未包含**任何完整资金快照或交易账号信息；
- 代码中**已不存在本机绝对路径**——原有的 5 处硬编码路径已全部改为
  `--data-dir` / 环境变量 / 自动搜索；
- 生成物（报告、页面）中也不再写入本机绝对路径。

同时按课程要求，仓库**不包含原始行情数据**（225 MB），一律通过 Release 获取。

## 已知边界

- 项目 1 的被动成交采用简化队列模型（不重建真实队列位置），
  因此模拟成交的时点与数量是近似而非精确。
- 项目 1、2 的十档核对**抽样**进行，不等于证明所有时间点的数据完整性；
  未命中的约 2–3% 集中在成交极活跃、消息速率高的标的。
- 项目 3 为**单日样本**：跨股票结论稳健，但"日内 U 形""VPIN 衰减"等时间维结论需多日验证；
  当日无涨跌停、波动温和，尾部事件未覆盖。
- 板块标签为人工映射，个别标的归类可能与其他口径不同。
