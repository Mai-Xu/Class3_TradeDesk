# 订单簿回放与模拟下单原型

基于本节实践课的 `sse50_20260923` 数据（上交所 Level-2 逐笔委托 / 逐笔成交 / 行情快照），
实现一个**本地运行**的订单簿回放 + 模拟下单原型：按股票逐笔回放买卖十档，
支持连续竞价限价委托、排队、部分成交、撤单、资金与持仓冻结，并提供浏览器操作页面。

原始行情数据沿用课程的 [Release 下载链接](https://github.com/aslan9/pku_quantllm/releases/tag/data-sse50-20260923)，
本项目包**不重复包含原始数据**；数据目录通过 `--data-dir` 配置，不依赖个人电脑路径。

## 快速开始

```bash
pip install -r requirements.txt

python run.py --data-dir /path/to/sse50_20260923     # 启动本地页面（默认 http://127.0.0.1:8770）
python run.py --validate                             # 运行数据验证并生成 reports/validation.md
python -m unittest discover -s tests -v              # 核心测试 11 项
python tools/smoke_http.py                            # 页面接口冒烟检查
```

`--data-dir` 省略时按以下顺序自动定位：环境变量 `OBSIM_DATA_DIR` → 项目同级的 `sse50_*` 目录 →
当前目录 → 向上搜索 `ord_*.parquet`。文件名中的日期自动识别，不写死。

## 功能

- **逐笔回放**：按股票回放买卖十档，处理新增挂单、撤单与成交事件。
- **模拟下单**：连续竞价限价委托，按价格和时间排队；即时吃单、部分成交、剩余挂单、撤单。
- **冻结与 T+1**：买入冻结资金、卖出冻结持仓；当日买入计入今仓，当日不可卖，日终结算后转可卖。
- **交易规则**：区分主板与科创板的申报数量与有效申报价格范围；校验价格最小变动单位、
  普通已上市股票的涨跌幅。
- **操作页面**：行情十档、模拟账户、委托记录、模拟成交记录；仅在本机运行。

## 交易规则（`obsim/rules.py`）

| 项目 | 主板 | 科创板 |
| --- | --- | --- |
| 单笔申报数量 | 100 股起，须为 100 股整数倍 | 200 股起，超出部分按 1 股递增 |
| 涨跌幅 | ±10% | ±20% |
| 连续竞价有效申报价格范围 | 价格笼子 ±2%（相对基准价） | 价格笼子 ±2%（相对基准价） |
| 最小变动单位 | 0.01 元 | 0.01 元 |

> 交易所业务细则存在版本差异，以上参数均在 `BoardRules` 中集中配置，可按课程口径调整。
> 卖出时若持仓不足最小申报量，允许一次性全部卖出。

## 重建要点：委托与成交联合处理

回放时同时消费逐笔委托与逐笔成交：

- 新增委托建单入簿，撤单按被撤数量减量；
- 成交按方向扣减**被动方（挂单方）**，集合竞价成交扣减双方。

**关键点**：上交所新增委托记录可能表示"立即成交后的剩余挂单量"，
因此不能再把已成交量从后出现的剩余挂单里重复扣减一次。采用该模型后，
全量回放中"无效扣减（超出挂单剩余量）"为 0。

字段映射（在缺少供应商说明的情况下，依据原始订单编号关联、事件编码与重放结果推断）：
`FunctionCode` 66/83 = 买/卖方向，`OrderKind` 65/68/83 = 新增/撤单/状态，
`OrderOriNo` 为按频道分配的交易所订单号（成交记录与撤单记录均引用它）。

## 验证结果

由 `python run.py --validate --sample 2400` 生成，完整报告见 [`reports/validation.md`](reports/validation.md)。

| 检查 | 结果 |
| --- | --- |
| 股票数量 | 50 |
| 完整重放的事件数（委托 + 成交，剔除盘后） | 10,066,831 |
| 撤单找不到原单 | 0 |
| 被动成交 / 集合竞价成交找不到挂单 | 0 |
| 挂单数量扣减超额 | 0 |
| 收盘累计成交量与快照一致 | 50 / 50 |
| 抽样十档盘口 + 累计成交量，直接按快照标注时间匹配 | 682 / 2389 |
| 同上，在标注时间所在秒内匹配 | 2320 / 2389 |
| 同上，加入相邻时间诊断后匹配 | 2323 / 2389 |

快照与逐笔业务时间存在偏差：绝大多数匹配样本需要向后搜索，最大偏移约 **980 ms**
（少量样本需要向前 10–20 ms）。时间对齐只用于离线核验，不用于让策略提前获得未来盘口。
未命中的约 2.7% 集中在成交极活跃、消息速率高的标的（如 600183），
残余误差来自被交易所略过的"立即成交"委托残量与亚秒级对齐不确定性。

## 边界与说明

- 盘后固定价格交易挂在频道 2301，逐笔委托中没有对应频道，核验时整体剔除该频道。
- 行情快照与逐笔业务时间存在亚秒级偏差；核验时在标注时间附近搜索订单簿状态，
  时间对齐**只用于离线核验**，不用于让策略提前获得未来盘口。
- 抽样核验不等于证明所有时间点的数据完整性。
- 模拟成交的被动成交采用简化队列模型（不重建真实队列位置）。
