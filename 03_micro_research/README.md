# 上证 50 逐笔数据微观结构深度研究

对 `sse50_20260923`（2026-09-23 上交所 Level-2 上证 50 样本）做**市场微观结构**的系统性研究，
与同目录下 `exchange_sim` / `orderbook_sim`（撮合复现）分工互补：本目录**不还原撮合**，
而是把数据当作真实市场切片，量化流动性、波动、订单流、订单行为、成交特征与跨股票联动。

## 核心发现（详见 report.md）

- **日内 U 形 + 午间断点**：开盘价差/波动/量同冲高，午间最清淡，尾盘再抬升；深度与波动严格反向。
- **最小变动价位主导流动性横截面**：相对价差与股价相关 −0.83；低价股被 0.01 元"顶"到 25 bp，高价股窄至 1 bp。
- **OFI 同期强(R²≈14%)、预测弱(0.2%–0.7%)**；越靠近盘口预测越强（买一 vs 十档），深档失衡在长视野反超。
- **大单冲击以永久成分为主**（均值口径 90% 永久），但中位数揭示过半是临时冲击。
- **远单快撤**：贴中间价撤单率 26.8%，离盘口 >20 跳升至 64.7%、存活仅 11 秒。
- **价差六成是逆向选择**（实现价差分解）；**波动升高不带来更高撤单率**；**拆单迹象明显**（同向委托 66%）。
- **快照-逐笔总量自洽 99.94%**，区间偏差来自 0.15–1.0 秒网关对齐偏移。

## 运行

```bash
python s01_overview.py    # ... 依序执行
python s14_extra.py
python s13_dashboard.py   # 生成看板
```

依赖：`pandas`, `numpy`, `pyarrow`, `matplotlib`（Python 3.13）。脚本按编号顺序执行；
`s02` 产出的 `out/snap_panel.parquet` 是后续多数脚本的输入（该文件是可再生中间产物，未入库）。

**数据目录**：`lib.py` 按 `--data-dir` 之外的方式自动定位，不写死本机路径——
优先读环境变量 `SSE50_DATA_DIR`（或 `OBSIM_DATA_DIR`），其次找本项目同级的 `sse50_*` 目录，
再退到当前目录 / 逐级向上搜索 `ord_*.parquet`。文件名日期自动识别。

```bash
# Windows PowerShell
$env:SSE50_DATA_DIR="D:\data\sse50_20260923"
# Linux / macOS
export SSE50_DATA_DIR=/data/sse50_20260923
```

> `out/micro_dashboard.html` 通过相对路径引用 `out/figures/` 下的图片，
> 移动或单独复制该 HTML 会丢图，请连同 `out/figures/` 一起拷贝。
